# WatchDog

[![CI Status](https://github.com/AY2627S1-CS2103T-T15-4/tp/actions/workflows/gradle.yml/badge.svg)](https://github.com/AY2627S1-CS2103T-T15-4/tp/actions/workflows/gradle.yml)
[![codecov](https://codecov.io/gh/AY2627S1-CS2103T-T15-4/tp/branch/master/graph/badge.svg)](https://codecov.io/gh/AY2627S1-CS2103T-T15-4/tp)

![Ui](images/Ui.png)

**WatchDog is a desktop application for managing a dog daycare centre.** Use keyboard commands to manage customers and dogs, link dogs to their owners, schedule activities, and track enrolments through a graphical interface.

* To start using WatchDog, head over to the [_Quick Start_ section of the **User Guide**](UserGuide.html#quick-start).
* To contribute to WatchDog, start with the [**Developer Guide**](DeveloperGuide.html).
